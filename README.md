# 🛡️ LogSentinel

Log-based intrusion and anomaly detector. Upload web server logs, detect brute-force attempts,
scanning, injection probes and abnormal traffic using rules plus machine learning, and triage
alerts in a role-based Streamlit dashboard with Google login.

[![CI](https://github.com/ParthKoli07/logsentinel/actions/workflows/ci.yml/badge.svg)](https://github.com/ParthKoli07/logsentinel/actions/workflows/ci.yml)

## Status
Phase 1: foundation (in progress).

## Ethics
Use only synthetic logs or logs from systems you own. Never commit real log data or secrets.
